# Security

Please report security problems in these skills privately to support@searchapi.io with "Security" in the subject, not in a public issue. Include the file, what an attacker could do, and steps to reproduce.

What the skills send and store is listed in the README under [Data and network](README.md#data-and-network). Your SearchApi key goes only to `www.searchapi.io` in the `Authorization` header and is never printed.

SearchApi's own security programme is described in its [Trust Center](https://security.searchapi.io).
